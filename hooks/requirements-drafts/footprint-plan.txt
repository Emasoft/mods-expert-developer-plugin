# Footprint plan of the requirements-drafts mod (TRDD-O5LUMKPW), compared with
# `claude plugin validate` by the quickstart's plan-diff.sh. One entry per line: <kind>: <items>.
#
# Observe: session.start (start: read the switch, register commands), prompt.submit (record typed
# text), classic.SessionStart (empty the list after /clear, /resume, /branch), command.run for the
# three commands, ui.render for the picker pane and for each UserMessage row.
hooks: session.start, prompt.submit, classic.SessionStart, command.run{command=requirements-drafts}, command.run{command=requirements-drafts-save}, command.run{command=requirements-drafts-pick}, ui.render{component=Pane, requestId=requirements-drafts-pick}, ui.render{component=UserMessage}
#
# Do, each call and what breaks without it:
#   $.store.get/set     the on/off switch would not survive a restart
#   $.command.register  the three commands would not exist
#   $.env.get (HOME)    the drafts folder ~/.claude/requirements-drafts could not be found
#   $.fs.exists/list    no dedup by hash: a second save would write a second file
#   $.fs.write          no draft file at all
#   $.clock.now         no created time and no file name
#   $.session.root/repo  the frontmatter would lack project-root and repo
#   $.session.id        no session in the frontmatter, and no per-session typed-message lists:
#                       one session's message could be saved from another
#   $.ui.toast          saves, refusals, "already saved" and a failed write would be silent
#   $.ui.open/close     no picker pane, and it would stay open after a pick
#   $.ui.invalidate     a row would keep its button after a save, the picker its old list
#   $.ui.resolve        no elements to draw with
#   $.ui.log            a failed start, command registration, write, record or reset would leave no trace
calls: $.clock.now (via saveDraft), $.command.register (via startRequirementsDrafts), $.env.get (via saveDraft), $.fs.exists (via saveDraft), $.fs.list (via saveDraft), $.fs.write (via saveDraft), $.session.id, $.session.repo (via saveDraft), $.session.root (via saveDraft), $.store.get (via startRequirementsDrafts), $.store.set, $.ui.close, $.ui.invalidate, $.ui.log, $.ui.open, $.ui.resolve, $.ui.toast
env reads: HOME
env writes: nothing
